# Disease Prediction System

🚀 **Live Demo:** https://ai-disease-prediction-system-2imjkyyasxbfwkbkpxjaaf.streamlit.app/

An AI-based educational disease prediction application that analyses selected symptoms and displays possible symptom matches.

## Technologies Used
- Python
- Streamlit
- Pandas
- Machine Learning concepts
## Features
- Select multiple symptoms
- Compare selected symptoms with example condition profiles
- Show the top three symptom matches and overlapping symptoms
- Include health-safety guidance and limitations

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important limitation
This is **not a medically validated disease-prediction model** and must not be used to diagnose, treat, or rule out any condition. The example symptom profiles are small and illustrative, and the overlap score is not a probability of having a disease. Consult a qualified healthcare professional for personal medical concerns; seek emergency care for severe or life-threatening symptoms.
